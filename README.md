# Language Learning Tools

Welcome to the repository for my language learning toolkit. Here is one of my experiments with vibe coding. My job is in healthcare, so I have to be more
careful at work, but I wanted to have a project where I can let the agents go free. I also have been wanting to get to fluency in Korean and I think this
toolkit has actually been helpful for me already. If you find it helpful, excellent!
It isn't 100% AI written, but I only get involved when I feel like doing so or need to do so.

Expect it to not be the most stable. I have been focusing more on building out what I want to have before I make it work nice.
